## Priority Issues

**[P1] Complete/undo failures are silent.**
Why: the one state this feature must never lie about (done vs not-done) is exactly what failure corrupts — no `onError`, no announcement.
Fix: inline row error + live-region announcement on failure; keep the row open.
Suggested command: `$impeccable harden`

**[P1] Outbox row keyboard double-activation.**
Why: Enter/Space on the inner Retry button both retries AND opens the detail modal — blocks keyboard users' core flow.
Fix: ignore keydown events from interactive descendants (`closest('button,a,input,select,textarea')` guard).
Suggested command: `$impeccable harden`

**[P1] Dashboard Tasks-due rows lack parent-deal context.**
Why: subject + date only — triage requires opening each row, the exact job the widget exists for.
Fix: include deal relation in the response, render deal title as secondary link.
Suggested command: `$impeccable clarify`

**[P2] Complete affordance is undiscoverable, sub-target, and unannounced.**
Why: 20px hover-revealed circles fail touch, low-vision, and SR users in one control.
Fix: ≥24px target with persistent ring, `aria-live` announcements, visible undo countdown.
Suggested command: `$impeccable polish`

**[P2] Warning-amber body text fails contrast (~2.2:1 on white).**
Why: status text some users cannot read; `--warning-ink` already exists and is unused.
Fix: map warn tones to `var(--warning-ink)` on light.
Suggested command: `$impeccable colorize`
